# metabolic-agent-bench
A benchmark and evaluation suite for metabolic reasoning agents, including tasks, prompts, scoring criteria, and reproducible evaluation pipelines.

Currently, tasks are extracted from a preprint paper: 
Comprehensive evaluation of LLM capabilities for interpretation and analysis of genome-scale metabolic models in metabolic engineering; doi: https://doi.org/10.64898/2026.06.03.730004
Some adjustments are made to adapt our own project.

Welcome to anyone has suggestions, examples, or edge cases that you think should be included. please raise an issue if you want to make contribution!
